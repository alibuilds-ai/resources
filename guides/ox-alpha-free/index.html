Five free ways to run Ox Alpha

Nobody has claimed this model, it has a million-token context window, and five different providers are currently handing it out for nothing. Here is where each one lives, the exact model id it expects, and what you are giving up by using it.

Ox Alpha appeared on OpenRouter on 20 August 2026 with no lab attached to it. It takes text, images and video, reads 1,048,576 tokens in one go, writes up to 131,072, and costs nothing while the preview lasts. OpenCode announced the free window as "the next week" without a timestamp, so plan around 27 August and expect it to end without warning.

The part worth understanding before you install anything: there is one model, sitting behind a handful of gateways, and every tool below reaches it over the same OpenAI-shaped API. Once you know that, picking a route is a two-minute decision instead of five signups.

The five routes at a glance

Those retention terms are not the same policy written four ways. OpenRouter's own model card says the provider keeps prompts and completions; OpenCode Zen says it keeps nothing. If you care about the difference, the route you pick is the decision.

Setting each one up

  1. OpenRouter: the one to try first

    Fastest way to see it work with no install at all: open the model page, sign in, and type into the playground. Nothing to configure and no card.

    For code, make a key at openrouter.ai/keys and call it like any OpenAI endpoint:

    curl https://openrouter.ai/api/v1/chat/completions \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"stealth/ox-alpha",
       "messages":[{"role":"user","content":"port this file to typescript"}]}'

    Same two values work in any OpenAI SDK: base URL https://openrouter.ai/api/v1, model stealth/ox-alpha. OpenRouter's documented free-tier caps (20 requests a minute, 50 a day, or 1,000 a day once you have ever bought $10 of credit) are written for model ids ending in :free. Ox Alpha is priced at zero without that suffix, so treat "generous rate limits" as an unmeasured promise rather than a number you can plan a job around.

  2. opencode: if you already work in a terminal agent

    curl -fsSL https://opencode.ai/install | bash   # or: npm i -g opencode-ai
cd your-project
opencode

    Inside the TUI: /connect, pick OpenCode Zen, paste the key it gives you, then /models and choose Ox Alpha Free. Use the picker rather than hard-coding the id, because this is a preview alias and it can be renamed under you. If the list is empty, the ids are opencode/x-preview-f-free on Zen and opencode-go/ox-alpha-free on the Go plan.

    Then /init so the agent writes itself a map of the repo before it starts editing.

  3. Command Code: no key to paste

    npm i -g command-code
cd your-project
cmd --model stealth/ox-alpha

    Command Code carries the model on every plan including the free one, so there is no gateway signup in the middle. /model switches mid-session without dropping context. They also say they built a tool-repair harness around it after benchmarking roughly 5B tokens, which matters more than it sounds. See the tool-call error rate further down.

  4. Hermes Agent: if you want it in chat apps, not a terminal

    curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
hermes portal    # browser login
hermes model     # pick Ox Alpha
hermes

    Hermes is MIT-licensed and runs the same agent through Telegram, Discord, Slack, WhatsApp, Signal, email or the CLI, which is the reason to pick it over the others. It does not host Ox Alpha itself; it routes through Nous Portal, OpenCode or OpenRouter, so set provider and the model slug in ~/.hermes/.env if you would rather bring your own OpenRouter key. Give it 64k of context or more; below that it misbehaves.

  5. Venice: if you want privacy framing and a chat window

    Venice lists it as stealth-ox-alpha, free, in the chat app at venice.ai/chat. For the API, make a key in venice.ai/settings/api and point an OpenAI client at https://api.venice.ai/api/v1. Same request shape as OpenRouter, different base URL and slug.

before you paste anything

Nobody has claimed this model. You are sending your code to an operator with no name, no jurisdiction and no support contract, and on the OpenRouter route they explicitly keep what you send. That is fine for a side project or a refactor of open-source code. It is not fine for client work, credentials, or anything under an NDA — and no route's privacy wording changes who is actually on the other end.

Is it actually good, or is it just free

The number that started the noise comes from a community run on a ten-task DeepSWE subset. Small sample, not an official leaderboard, but the gap is wide enough to be interesting:

What the hype posts leave out, all of it from OpenRouter's own live metrics on the model:

  • Median throughput sits around 19–24 tokens a second. It is not fast, it is thorough. Long agent runs feel slow.
  • Average tool-call error rate of 2.16%, which is exactly why Command Code wrote a repair harness around it.
  • It accepts response_format: json_object but does not enforce a JSON schema. Anything downstream that assumes strict structured output needs its own validation.
  • It is labelled a reasoning model, yet the live traffic breakdown reports zero reasoning tokens. Nobody outside the lab knows what that means.
note

This is the fifth anonymous model dropped on OpenRouter in six months, and the previous four were all later claimed by Chinese labs — Zhipu, Xiaomi, Ant and Meituan. Ox Alpha's tokenizer is a near-exact match for GLM's, and one researcher says a deliberately malformed request made the server return a Java stack trace on a route matching Zhipu's documented API path. Strong circumstantial evidence, not a confirmation. No lab has claimed it.

When the free week ends

Every previous stealth drop either renamed itself, moved to paid, or vanished. Two things make that survivable: keep the model id in one config value rather than sprinkled through your code, and stay on an OpenAI-compatible gateway so switching to whatever replaces it is a two-line change. If the model does get claimed, the same weights will almost certainly reappear under a real name and a real price.

if you copy one thing

Take the OpenRouter playground route first, spend ten minutes on a real task from your own repo, and decide from that. Every provider on this page is repeating the same benchmark screenshot at you. Ten minutes of your own code is worth more than all of them.
